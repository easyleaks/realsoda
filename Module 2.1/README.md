# Чудо Обувь

Сделал приложение на C# Windows Forms с подключением к PostgreSQL. В каталоге отображаются изображение, название, производство, категория, состав, цена и количество товара.

Больше пяти пар отображается как «много», пять и меньше как «мало». Остаток до трёх пар включительно выделяется красным. Если товар не заказывали в прошлом календарном месяце, применяется скидка 25%. Для отсутствующей картинки используется заглушка. Оформление сделано по заданию.

Исходники открываются через ChudoObuv.sln. Готовое приложение находится в build. Для запуска нужен .NET 8 Desktop Runtime x64 и база chudo_obuv из первого модуля. Пароль PostgreSQL нужно указать в build/connection.txt.
