# Чудо Обувь

Сделал базу данных магазина обуви в PostgreSQL. Создал таблицы товаров, размеров, остатков, пользователей, ролей, категорий, заказов и позиций заказов. Настроил ключи и связи, загрузил данные из файлов задания.

В chudo_obuv.sql находятся структура и данные базы. Схема таблиц сохранена в ER-diagram.pdf.
