# Чудо Обувь

Сделал базу данных в PostgreSQL, настроил ключи и связи между таблицами. Загрузил товары, пользователей, размеры, остатки и заказы из файлов задания.

Сделал приложение на C# Windows Forms. В каталоге выводятся картинки товаров, наименование, производство, категория, состав, цена и количество. Больше пяти пар отображается как «много», пять и меньше как «мало». Остаток до трёх пар включительно выделяется красным.

Если товар не заказывали в предыдущем календарном месяце, применяется скидка 25%. При отсутствии картинки показывается заглушка. Логотип, иконка, шрифт и цвета взяты из задания.

Для запуска нужно создать базу chudo_obuv, выполнить chudo_obuv.sql и указать пароль PostgreSQL в build/connection.txt. Приложение запускается через build/ChudoObuv.exe. Исходники открываются через ChudoObuv.sln.
