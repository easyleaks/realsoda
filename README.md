# Чудо Обувь

Модули 1–3. База PostgreSQL содержит модели обуви, размеры, остатки, пользователей и заказы. Структура связей приведена в ER.pdf.

Для запуска создайте пустую базу chudo_obuv и восстановите chudo_obuv_DB.sql через psql. Установите .NET Desktop Runtime 10 x64 и запустите Приложение/Чудо Обувь.exe. Программа подключается к localhost:5432 как postgres с учебным паролем 1234. Для другого подключения задайте строку Npgsql в переменной среды SHOE_DB.

Гость просматривает каталог. После входа по логину (например, isivanov) доступны поиск, фильтр категории, сортировка, выбор размера и количества. Корзина позволяет изменить количество пар, удалить позицию или отменить заказ. При подтверждении сохраняются заказ и цена покупки, уменьшаются остатки. Программа применяет скидку 25 % к моделям без продаж за предыдущий календарный месяц.

Исходный проект Windows Forms находится в Shop. Для сборки откройте .csproj в Visual Studio с поддержкой .NET 10 и восстановите пакет Npgsql.
